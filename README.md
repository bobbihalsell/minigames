# Mini Games Collection

A collection of text-based games implemented in Python. This project includes 12 different games that can be played directly in the terminal.

## Games Included

1. **Number Guessing Game (Player Guesses)** - Try to guess the computer's number
2. **Number Guessing Game (Computer Guesses)** - The computer tries to guess your number
3. **Rock Paper Scissors** - Classic game with best-of-X rounds
4. **Hangman** - Guess the word one letter at a time
5. **Random Band Name Generator** - Create unique band names
6. **Love Calculator** - Calculate compatibility between two names
7. **Find the Treasure** - Text-based adventure game
8. **Caesar Cipher** - Encrypt and decrypt messages
9. **Blackjack** - Card game against the computer
10. **Higher or Lower** - Guess which celebrity has more Instagram followers
11. **Tic Tac Toe** - Play against an AI opponent
12. **Word Scramble** - Unscramble letters to guess the word

## How to Run

Clone or download this repository
Run the main file:
   ```
   python main.py
   ```

## How to Play

When you start the program, you'll be greeted with options to:
- Browse the game menu and select a specific game
- Play a randomly selected game
- Exit the program

Each game includes clear instructions and input validation to guide you through gameplay.

No additional libraries required (uses only standard library)
